# Data
Impact of Bottom Trawling on Suspended Particles in UK Shelf Seas
This repository contains the R code used for data analysis and figure generation for my MRes thesis on the effects of bottom trawling on suspended particulate matter in UK shelf seas.
The code includes analyses of CTD, UVP and EcoTaxa data.
The datasets are not included in this repository because they are unpublished research data and are not currently publicly available.
The code is provided to document the analysis workflow used in the thesis.
